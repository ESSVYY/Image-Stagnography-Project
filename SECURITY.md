# Security Policy

PixelVault treats security as a core product requirement.

## Supported Versions

The current development branch is supported while this project is under active development.

## Reporting a Vulnerability

Please report issues privately through the repository’s security channel or by contacting the maintainer directly. Include:

- A description of the issue.
- The affected component.
- Reproduction steps.
- Any relevant screenshots or logs, with secrets removed.

## Security Principles

- No password logging.
- No permanent storage of uploaded images or extracted content.
- Authenticated encryption for hidden payloads.
- Strict file and image validation.
- Secure defaults for headers and CORS.
