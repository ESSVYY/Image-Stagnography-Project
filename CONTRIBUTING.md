# Contributing

Thanks for helping improve PixelVault.

## Development Rules

- Keep changes focused and minimal.
- Preserve the privacy-first architecture.
- Avoid introducing paid services or permanent storage dependencies.
- Add tests for behavior changes.
- Update the documentation when user-facing behavior changes.

## Local Workflow

1. Branch from the latest main branch.
2. Make your changes.
3. Run the relevant build and test commands.
4. Open a pull request with a concise summary and verification notes.

## Code Style

- Use TypeScript strict mode.
- Prefer small reusable functions.
- Avoid `any` unless unavoidable.
- Keep security-sensitive logic explicit.
